# Radar de Carreira Almir — pacote público recuperado

Origem: <https://radar-de-carreira-almir.jazzy-siren-4604.chatgpt.site/>

Este diretório contém os artefatos públicos disponibilizados pelo portal em
4 de agosto de 2026:

- `index.html` — HTML renderizado para visitantes sem sessão;
- `assets/index-DaLQGn7a.css` — estilos publicados;
- `assets/Dashboard-St4gNods.js` — módulo compilado do painel autenticado;
- demais arquivos em `assets/` — runtime e dependências compiladas.

## Limitação importante

Este não é o projeto-fonte React/TypeScript original. O ChatGPT Sites publicou
somente bundles JavaScript compilados e não disponibilizou source maps. O
projeto original deve ser aberto em ChatGPT > Sites > Radar de Carreira Almir >
Editar. Sem essa origem, nomes de componentes, comentários, organização de
pastas e tipos TypeScript não podem ser recuperados fielmente.

Os arquivos deste pacote servem para auditoria, preservação visual e referência
durante a reconstrução do portal. Recursos de autenticação e APIs continuam
dependendo do domínio e da infraestrutura do ChatGPT Sites.
